### Docs
- **The Calibre on Windows runbook now leads with pull mode** (#2834). Pull needs no shared drive, path remap, inbound firewall rule or fixed PC address, so it is the recommended way to connect a desktop Calibre, with push kept for Calibre in a container or on a server. The Calibre docs and the quick answers now describe the delivery queue (books wait while Calibre is closed, failures retry with backoff, Retry failed instead of rerunning Push all), multi format delivery, how to keep the pull key safe, and the plugin status messages seen in a real setup, including why a `localhost` Bindery URL can make every request take about 20 seconds on Windows.
