### Fixed
- **A single-file audiobook is now named from the audiobook file template** (#2900): with `naming.audiobook_file_template` set, a folder of tracks was renamed but a lone `.m4b` kept its download name. It now gets the same name a track would, and so does a folder holding just one track. Put `{Part}` in a group with its own text, like `{Title}{ - Pt. Part:3}.{ext}`, and the group is left out when there is only one file, giving `The Shining.m4b`; written bare, as in `{Title} - Part {Part:3}.{ext}`, the single file is numbered as part 1. Settings now accepts `{Part}` inside such a group, which it used to reject. **Rename files** and the Fix Match preview propose the same name for a single-file audiobook already in the library. With no template set nothing changes. Thanks zikeji for the report.
