### Fixed
- Opening the rollback preview for a Calibre import with nothing to undo, such as a dry run, no longer crashes the settings page. It now says there is nothing to roll back and keeps Apply disabled. The Audiobookshelf rollback preview gets the same fix.
- A browser tab left open across an upgrade now reloads itself once on iPhones and iPads instead of showing the error page. Bindery answers a request for a missing script or stylesheet with a 404 rather than the app page, and the reload check recognises the Safari, Chrome and Firefox messages for a script that came back as a web page.
