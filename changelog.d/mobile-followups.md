### Fixed
- **Phone follow ups** (#3052). Settings no longer jumps as it loads: the Security section used to appear a moment late and push everything under it down the screen. On a 320px phone the Default monitor mode dropdown in Settings, Metadata, the date fields in Logs and the Queue's Match to book search all fit the screen again, with nothing cut off. The More menu on an author page opens upward when it is near the bottom of the screen instead of running off it. On a phone each user on the Users page is a card with its Reset password and Delete buttons in view, instead of a table that hid them off to the side. Pagination, Sort and Filters, the Download link on Books, the Series actions, Retry all failed and Clear all failed, the Queue's time toggle, Add Indexer and the selection bar's buttons are easier to hit with a finger. The page now tells the browser and screen readers which language the interface is in, so they no longer read a translated interface as English.
