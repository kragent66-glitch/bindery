### Fixed
- **Automatic search no longer grabs a same titled book by a different author**: the release checks added in v1.35 to stop grabs like Edward Luttwak's "Coup d'État" for Ben Coes's "Coup d'Etat", "The Power of Writing It Down" for "Power Down", or "12 More Rules for Life" for "12 Rules for Life" never reached a real search. The relevance filter existed as two copies, the guards went into one, and both automatic search and the interactive Search button run the other. There is now a single implementation, so every guard applies to every search. The interactive search panel also says which check dropped a release: a different author for this title, or title words split by words the title does not have.
