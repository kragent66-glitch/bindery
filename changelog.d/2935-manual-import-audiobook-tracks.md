### Fixed
- **Importing an audiobook's tracks from a folder keeps them all in one place** (#2935): scanning an audiobook's own folder lists every track as a row, and importing those rows for one book ran each track as a separate audiobook. Running together, the tracks split across "Title" and "Title (2)" folders, could overwrite each other when an audiobook file template was set, and every track after the first was marked imported without being moved. Tracks imported together for the same book now land in one audiobook folder, named from the audiobook file template, the same as a downloaded multi part audiobook. A row now offers to use its book for the other tracks in the same folder, so the book is picked once instead of once per track, and importing onto a book that already has an audiobook is refused with a reason instead of reporting a success that moved nothing. Thanks fearvector on Discord for the report.
