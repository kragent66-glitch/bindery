### Fixed
- **Automatic search no longer grabs a longer book that contains your title** (#2812): the check added in v1.35 that stops "The Power of Writing It Down" passing for "Power Down", or "Beyond Order: 12 More Rules for Life" for "12 Rules for Life", only ran on a fallback path, so automatic search and the interactive Search button never used it. The same check also turns away a release for the wrong volume when both spell it the same way, such as "Volume 16" for a book titled "Volume 17". The relevance filter is now one piece of code shared by every search, so a check cannot reach one path and miss the other again. The interactive search panel also says which check dropped a release: a different author for this title, or the title's words with other words or numbers among them.
