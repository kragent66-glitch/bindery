### Fixed
- Phones no longer capitalise or autocorrect usernames, hosts, URLs and API keys, show a number pad for download client ports, and label the keyboard's return key Search in search boxes (#3052).
- Password managers on iOS and Android stop filling your Bindery login into API key, token and download client credential fields, and stop offering to save those keys as your password (#3052).
- File paths, rename previews and import errors wrap on small screens instead of hiding the rest behind a hover tooltip, and an import row's short reason can be tapped to show the full explanation (#3052).
- The Links menu on a book now closes on a second tap on touch screens, and settings switches have a larger tap area (#3052).
