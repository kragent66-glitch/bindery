### Fixed
- **An audiobook no longer lands on a later book in its series** (#2934): when one book in a series is titled like "The Primal Hunter 3" and another like "The Primal Hunter 17: A LitRPG Adventure", Bindery could not tell the two numbers apart once a subtitle followed the number, so volume 3's files were attached to volume 17. Volume 3 then stayed Wanted with an import in its history and nothing on the book. Library scans, Import from a folder and adding new books to an author now compare the series number wherever it sits in the title. Files already attached to the wrong book stay where they are: use Forget this file on the wrong book, then run a library scan and it goes to the right one. Thanks fearvector for the report.
