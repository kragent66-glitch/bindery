### Fixed
- **Calibre Test connection checks a real book, not just the library root** (#2831): with the Bindery Bridge plugin, Test connection only asked whether Calibre could see the library root. That path matches the push path remap exactly and skips the part that builds a book's path, so Test passed while every push was about to fail. It now also asks Calibre to open one real book (the newest imported ebook, or the first file under the library root) through the remap, and names the exact path it sent when Calibre cannot see it. When that path starts with a drive letter, it explains that a mapped drive belongs to one Windows logon session and suggests the share address instead. Paths in these messages no longer show doubled backslashes. Test connection also warns when the bridge is older than 0.6.2, which fixes pushes to long network share paths (0.6.1) and the empty book a failed add could leave in Calibre (0.6.2).
