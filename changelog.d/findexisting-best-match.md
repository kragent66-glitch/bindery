### Fixed
- **Adding an author no longer attaches a file to the wrong book** (#2941). When a new book's title was a shorter version of another title by the same author, Bindery could take the first library file that roughly matched, so "Harry Potter" claimed "Harry Potter en het vervloekte kind.epub" and the real match was left without its file. Bindery now compares every matching file and every book of the author, gives the file to the exact title, and leaves the book Wanted and searchable when two matches are too close to call. Thanks to foobarbigtime for the original report.
